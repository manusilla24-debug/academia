# Código abierto utilizado

El componente `src/components/ui/card.tsx` adapta el patrón de componentes Card del proyecto [shadcn/ui](https://github.com/shadcn-ui/ui), concretamente `apps/v4/registry/new-york-v4/ui/card.tsx`. Se modificaron las clases y los elementos semánticos para esta aplicación. La organización visual usa como referencia su ejemplo abierto de dashboard, con contenido y estilos propios.
